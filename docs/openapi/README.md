# OpenAPI Specifications
**Version:** v0.2.1  
**Last Updated:** 2026-07-09

This folder contains the OpenAPI contracts for the Rione services and the API gateway.

- `api-gateway.openapi.yaml` documents the public routes exposed by the gateway.
- `user-service.openapi.yaml` documents the user service API.
- `social-service.openapi.yaml` documents the social service API.
- `post-service.openapi.yaml` documents the post, comment, and reaction API.
- `notification-service.openapi.yaml` documents the notification service read-side API.

Actuator endpoints are intentionally excluded from these business API contracts.
