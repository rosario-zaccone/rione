# API Gateway Ubiquitous Language
**Version:** v0.1.0  
**Last Updated:** 2026-06-17

| Term | Definition | Notes |
|------|------------|-------|
| API Gateway | The public HTTP entry point for Rione service APIs. | |
| Gateway route | A public path that forwards traffic to a backend service. | |
| Backend service | A Rione service behind the gateway. | User, Social, Post, or Notification Service. |
| Public API | An endpoint exposed through the gateway. | |
| CORS policy | Cross-origin request policy applied to browser clients. | |
| Preflight request | Browser request used to check CORS permissions before the actual request. | |
