# Ubiquitous Language
**Version:** v0.1.2  
**Last Updated:** 2026-06-11

This section defines the shared vocabulary used by domain experts, developers, and stakeholders. All discussions, requirements, models, and code should consistently use these terms.

| Term            | Definition | Notes |
|-----------------|--------|--------|
| User            | A registered person who uses the platform to participate in one or more neighbourhood communities. | |
| Neighbour       | A user who belongs to the same neighbourhood as another user. | |
| Neighbour request | A request sent by one user to another user to establish a neighbour connection. | The recipient can accept or decline the request. |
| Neighborhood    | A local community space that represents a specific residential area, street, district, or rione. | Use one spelling consistently in code and documentation. |
| Post            | A message published by a user inside a neighbourhood to share information, ask questions, or start a conversation. | |
| Warning post    | A post used to alert neighbours about a local risk, disruption, safety issue, or urgent situation. | |
| Event post      | A post used to announce or coordinate a local event happening in the neighbourhood. | |
| Help post       | A post used to ask neighbours for assistance, recommendations, borrowed items, or practical support. | |
| Discussion post | A post used for general conversation, opinions, updates, or non-urgent neighbourhood topics. | |
| Reaction        | A simple response that a user adds to a post to express positive or negative feedback. | Represented as a like or not-like, similar to a thumb reaction in social platforms. |
| Post score      | A community feedback value that reflects how useful, relevant, or trusted a post is. | Usually derived from votes or reactions. |
| Post comment    | A reply written by a user in response to a post. | |
| Blocked user    | A user that another user has chosen to prevent from interacting with them or viewing their activity where privacy rules apply. | |
| Notification    | A message sent by the platform to inform a user about relevant neighbourhood activity, such as comments, mentions, events, warnings, or moderation actions. | |
