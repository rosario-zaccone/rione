# Post Service Ubiquitous Language
**Version:** v0.2.1  
**Last Modified:** 2026-07-09

| Term | Definition | Notes |
|------|------------|-------|
| Post | A message published by a user inside a neighbourhood. | |
| Public post | A post visible to eligible users in the author's neighbourhood. | Does not require an active neighborship with the author. |
| Private post | A post visible to its author and to same-neighbourhood users with an active neighborship with the author. | Hidden from same-neighbourhood users without active neighborship. |
| Warning post | A post used to alert neighbours about a local risk, disruption, safety issue, or urgent situation. | |
| Event post | A post used to announce or coordinate a local event happening in the neighbourhood. | |
| Help post | A post used to ask neighbours for assistance, recommendations, borrowed items, or practical support. | |
| Discussion post | A post used for general conversation, opinions, updates, or non-urgent neighbourhood topics. | |
| Reaction | A simple response that a user adds to a post. | |
| Post score | A community feedback value that reflects how useful, relevant, or trusted a post is. | Usually derived from reactions. |
| Comment | A reply written by a user in response to a post. | |
| Active neighborship | An accepted and currently active relationship between two users. | Required to view another user's private posts. |
| Own posts | Posts authored by the acting user. | Includes the user's public and private posts. |
| Eligible post | A post the acting user is allowed to view and interact with. | Determined by neighborhood, visibility, active neighborship, and blocking rules. |
| Removed comment | A comment hidden from normal discussions. | The parent post remains. |
