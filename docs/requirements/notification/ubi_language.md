# Notification Service Ubiquitous Language
**Version:** v0.1.1  
**Last Modified:** 2026-07-09

| Term | Definition | Notes |
|------|------------|-------|
| Notification | A message sent by the platform to inform a user about relevant neighbourhood activity. | Includes neighbour requests, post interactions, and moderation events. |
| Recipient | The user who receives a notification. | |
| Notification state | Whether a notification is unread or read. | |
| Unread notification | A notification the recipient has not viewed. | |
| Read notification | A notification the recipient has viewed or marked as read. | |
| Delivery attempt | An attempt to deliver a notification through an available channel. | |
| Delivery failure | A failed delivery attempt. | Must not roll back the original action. |
